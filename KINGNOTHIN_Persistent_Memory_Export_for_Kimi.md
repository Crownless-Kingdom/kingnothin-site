## Governing Purpose

KINGNOTHIN exists to help people remain free in their own minds while learning to navigate the future with privacy, agency, discernment, and wisdom.

Build for ordinary people, non-experts, the uninitiated, the left behind, and the person who knows something is wrong but cannot yet name it.

The person should leave feeling:

- I finally understand.
- I can do this.
- I am not powerless.
- This place respects my intelligence.
- I have a practical next step.

Never create dependence, confusion, fear, extraction, humiliation, or shallow spectacle.

## Voice And Message

Sound like a patient teacher, careful historian, thoughtful scientist, future-facing field guide, and trusted advisor.

Do not sound like a marketer, influencer, motivational speaker, politician, cult leader, doomsday prophet, tech bro, crypto evangelist, conspiracy theorist, or corporate chatbot.

Use this editorial sequence:

1. Consequence: what is happening to the person?
2. Mechanism: what system creates it?
3. Meaning: why does it matter beyond the moment?
4. Action: what can be done now?

The message must land before the brand:

1. Insight
2. Context
3. Action
4. Principle
5. Invitation

Primary institutional tagline:

`THE REVOLUTION HAS NO THRONE.`

Keep it on one centered line unless the user specifically requests two lines.

Foundational line:

`Privacy is the foundation. Agency is the goal. Wisdom is the destination.`

Use one major tagline per surface. Do not stack slogans.

## Visual And Creative Direction

KINGNOTHIN should feel:

- Futuristic without becoming science fiction.
- Premium without becoming corporate.
- Industrial without becoming dystopian.
- Ancient without becoming medieval.
- Rebellious without becoming noisy.
- Calm, intelligent, useful, accessible, and durable.

Use Swiss editorial precision, near-future industrial design, quiet luxury, institutional seriousness, technical clarity, ancient symbolic weight, modern accessibility, architecture, observatories, maps, civic space, navigation, light, and human craft.

Wayfinding is a strong default visual language: maps, compasses, navigation instruments, plotted routes, horizons, constellations, observatories, field guides, archives, and `YOU ARE HERE` markers.

The project should guide ordinary people toward an extraordinary future. Keep that audience explicit rather than implied.

Avoid generic startup layouts and generic technology imagery. Specifically avoid neon cyberpunk, Matrix-style code, anonymous masks, skulls, chains, cages, hacker costumes, rain-soaked dystopian cities, surveillance cameras as default shorthand, chrome AI heads, glowing brains, glitch overload, and royal imagery that glorifies domination.

The Capote/Kubrick principle governs the creative pulse:

- Capote: precise observation, intimate mechanisms, disciplined language, elegant exposure of falsehood.
- Kubrick: symmetry, silence, patience, architectural composition, controlled tension, deliberate reveals.
- The result should be composed, intelligent, watchful, and unafraid.
- Interaction should reveal, decrypt, expose, protect, clarify, or transform something meaningful.

No neon, corporate blue, or pink-purple gradients. Use gold as a crown, not a carpet. Use crimson for meaning, never decoration. Use jade for restoration, progress, unlocks, signal, and controlled technological life.

Only these fonts are approved:

- `GC-Epic-Pro-Demo`: major hero headlines, section titles, brand statements, tagline moments, dramatic reveals, high-impact phrases.
- `Prototype`: smaller headings, labels, navigation accents, buttons, module titles, technical UI, status indicators, animated sequences.
- `Dosis`: paragraphs, explainers, mission copy, longer reading, accessibility-focused content.
- `Exo`: subheadings, short explanatory blocks, card descriptions, microcopy, footer text, form labels.

Do not introduce Jost, Space Mono, Inter, Roboto, Arial, Helvetica, Montserrat, Poppins, `monospace`, or a system font as the intended brand font. A generic fallback such as `sans-serif` may appear only at the end of an approved font stack for browser safety.

Local font files live under `assets/fonts/`.

## Composition, Motion, Accessibility

KINGNOTHIN is unapologetically symmetrical by default.

Center major headers, subheadings, section titles, mission statements, high-impact text, introductory paragraphs, closing statements, and calls to action unless there is a clear functional or aesthetic reason not to.

Line breaks must feel composed. Asymmetry is a purposeful disruption for tension, warning, extraction, broken systems, or interactive reveals. Return to symmetry after the disruption.

Motion should reveal cause and consequence:

- Hover and focus: 200-300ms.
- Panels: 300-500ms.
- Reveals: 500-700ms.
- No bounce or elastic easing.
- No motion that blocks reading.
- Respect `prefers-reduced-motion`.

Meet WCAG 2.1 AA minimum. Use semantic HTML, visible focus states, meaningful alternative text, keyboard support, strong contrast, body text of at least 16px, comfortable line length, and no reliance on color alone.

No invasive analytics, tracking pixels, pre-checked boxes, dark patterns, manipulative countdowns, or unexplained collection. Prefer local processing and privacy-friendly forms.

## Local Preview And Validation Memory

Do not rely on `file://`. Serve the static site over loopback HTTP.

A previously reliable Windows runtime was:

`C:\Users\Owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`

Example:

```powershell
& 'C:\Users\Owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 8765 --bind 127.0.0.1
```

Then verify:

```powershell
Invoke-WebRequest -Uri 'http://127.0.0.1:8765/index.html' -UseBasicParsing
```

This path is machine-specific and may not exist elsewhere. Any available Python 3 static server is acceptable.

Important Windows behavior:

- A shell-launched server may exit even after an initial HTTP 200.
- Re-probe immediately before browser navigation.
- If a browser tab shows `ERR_CONNECTION_REFUSED`, restart the server persistently and open a fresh tab.
- Leave the successful visible browser tab open when the user asked to see the site.

Focused static validation:

- Run JavaScript syntax checking on `script.js`.
- Run `git diff --check`.
- Search exact old/new copy or removed hooks with `rg`.
- Compare normalized extracted HTML text when exact copy matters.
- Inspect desktop and mobile, including about `390x844`.
- Check for horizontal overflow.
- Check browser console errors.
- Confirm reduced-motion behavior.

On the prior Codex Windows environment, the bundled Node executable was:

`C:\Users\Owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe`

Again, locate the equivalent runtime on the new device rather than assuming this path exists.
